# PRO 연습장

아이패드(태블릿) 브라우저에서 SW 역량테스트 PRO 문제를 풀고 **컴파일·실행·테스트**할 수 있는 웹 도구입니다.
설치할 것 없이 Safari에서 열면 됩니다.

## 기능

- **C++ / C / Java / Python** 지원, 컴파일러 버전 선택 (기본: gcc 13.2, JDK 21, Python 3.12)
- PRO 문제처럼 **여러 파일** 구성: `main.cpp` + `solution.cpp`, 헤더, `sample_input.txt` 등
  - 첫 번째 파일(● 표시)이 시작 파일, 나머지 C/C++ 소스는 자동으로 함께 컴파일
  - Java는 `public class Solution` 그대로 사용 가능 (자동 처리)
  - `freopen("sample_input.txt", "r", stdin)` 도 동작 (파일 탭에 추가하면 됨)
- **테스트 케이스 여러 개**: 입력 / 기대 출력 저장, `전체 테스트`로 정답·오답·컴파일 에러·런타임 에러 판정
  - 오답이면 처음 다른 줄을 보여줌, 줄 끝 공백 무시
  - 에러 메시지의 `solution.cpp:12:5` 를 누르면 해당 줄로 이동
- 패드용 **기호 키 줄** (Tab, `{}`, `;`, `<`, `>`, `&`, `|`, 방향키, 되돌리기, 주석)
- 문제별 저장(이 기기 브라우저에만 저장), 복제, 전체 코드 복사, 기기 파일 가져오기
- 단축키: `⌘/Ctrl + Enter` 실행, `⇧ + ⌘/Ctrl + Enter` 전체 테스트, `⌘/Ctrl + /` 주석
- 라이트/다크 테마, 글자 크기 조절, 입력이 이상할 때 쓰는 단순 편집기 모드

## 문제 묶음 불러오기 (zip)

`문제 목록` → **문제 묶음 불러오기**에서 zip 파일(또는 여러 파일)을 고르면:
- 코드 파일(.cpp .c .java .py)은 각각 **문제**로 들어갑니다 (zip 이름으로 묶여 표시).
- 이름에 같은 `p7` 같은 번호가 붙은 글 파일은 그 문제의 파일 탭에 같이 붙습니다.
- 나머지 글·이미지(문제 원문, 요약 카드)는 상단 **자료**에 들어가고, 글 자료는 `이 문제로 풀이 만들기`로 바로 풀이를 시작할 수 있습니다.
- 같은 zip을 다시 불러와도 이미 있는 문제는 덮어쓰지 않습니다 (작성 중인 코드 보호).
- 압축은 브라우저 안에서 풀리고 **내용은 그 기기에만 저장**됩니다. 서버나 이 저장소에 올라가지 않습니다.

## 동작 방식

코드는 [Wandbox](https://wandbox.org) 공개 컴파일 서버에서 실행됩니다. 따라서 **인터넷 연결이 필요**하고,
화면의 시간은 네트워크를 포함한 왕복 시간이라 실제 실행 시간과 다릅니다.
(PRO 문제의 성능 측정은 코드 안에서 `clock()` 등으로 직접 재 보세요.)

## 아이패드에서 쓰기

1. GitHub 저장소 **Settings → Pages** 에서 Source를 *Deploy from a branch* 로, 이 파일들이 있는 브랜치와 `/ (root)` 를 선택
2. 잠시 후 `https://<사용자명>.github.io/pro_with_clau/` 주소가 열림
3. Safari 공유 버튼 → **홈 화면에 추가** 하면 앱처럼 전체 화면으로 실행

## 파일

- `index.html` — 화면
- `app.js` — 동작 (편집기, 테스트, Wandbox 호출)
- `vendor/codemirror/` — 코드 편집기 (CodeMirror 5.65.16, MIT)
- `vendor/jszip/` — zip 압축 해제 (JSZip 3.10.1, MIT)
